# Live Meta, no snapshot per Día

Cumplimiento of a fecha is judged against the Meta as it stands now. Changing the Meta in Ajustes recolors every Día. A Meta-per-Día snapshot would freeze yesterday when the target changes, which fights a personal tracker that already rewrites history when an Alimento is edited (ADR-0006). Colors are derived from that Día’s Comidas and the current Meta; they are never persisted.
