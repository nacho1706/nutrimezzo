# Renglón stores Alimento plus Cantidad, not a macro snapshot

Confirmed Renglones point at an Alimento and a Cantidad. Día totals are computed. Fixing an Alimento's per-100 g Macros rewrites history. A snapshot-on-confirm model would freeze the diary but split the truth between label and log; this is a personal tracker, so correcting the Alimento is correcting the week. Ask-on-edit can wait.
