# MVP is diary + notes capture, not Fitia

NutriMezzo v0 is a local daily macro tracker with notes-style Comida capture, 1–2 Propuestas per Renglón, and an Alimento catalog. Photo, voice, barcode, meal plans, recipes/composite foods, body weight, fasting, health-platform sync, accounts, and micros are out. Those are extra products; including them would bury a Flutter beginner before the logging loop works.
