# Cumplimiento is judged against the Meta as it stands now

A Día with Comidas gets a Cumplimiento from the current Meta: calories are a ceiling, protein is a floor, carbs and fat do not participate. There is no Meta-per-Día snapshot. Changing the Meta in Ajustes rejudges every Día, same as editing an Alimento rewrites past totals (ADR-0006). Freezing each day’s color against the Meta that was in force then would keep the month still, but the calendar and Ajustes would disagree. This is a personal tracker: the number that matters is the one now.
